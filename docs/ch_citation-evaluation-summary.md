# Week 2 引用评测公开摘要

## 1. 文档用途

本文件是阈值 `0.60`、V2 引用评测的公开脱敏摘要。

完整本地报告包含模型回答、参考答案和引用明细，因此不提交到公开仓库。本文不包含原始 Chunk、引用 `excerpt` 或完整模型回答。

## 4. 逐题状态

### 已回答且引用完整

```text
q002 q003 q004 q005 q011 q012 q014
```

这些问题返回的引用全部匹配 Gold 文件与位置，没有接受模型自造的文件名、页码或 Chunk ID。

### Gold 可回答但在线 API 拒答

```text
q001 q006 q007 q008 q009 q010 q013 q015 q016
```

其中存在两类原因：

1. q007、q008、q009 的正确证据没有进入 Top-3；
2. 其他问题的 Top-3 已包含正确证据，但 Top-1 低于 `0.60`，被代码门控拒答。

### 无答案题正确拒答

```text
q017 q018 q019 q020
```

这些问题都返回 `abstained=true` 和空引用。

## 5. V2 改进

阈值 `0.60` 的第一轮报告曾出现 9 条返回引用中只有 8 条正确，引用正确率为 `0.889`。

Prompt 增加“最小充分证据集合”规则后，V2 只返回回答实际需要的 8 条证据，8 条全部正确：

```text
引用正确率：0.889 → 1.000
完整证据回答率：0.375 → 0.438
```

## 6. 验收结论

引用真实性和无答案拒答表现稳定，但在线可回答率只有 `7/16`。因此不能仅凭 `Recall@3 = 0.850` 判定线上 RAG 已达到可用质量。下一阶段需要改进检索和门控，同时保持引用正确率与无答案正确拒答率。
