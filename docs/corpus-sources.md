# Robot Knowledge Base 语料说明

记录日期：2026-08-10

## 1. 文档目的

本文档记录 Robot Knowledge Base 使用的语料来源、授权情况、脱敏情况、内容范围和稳定定位方式。

所有原始文档只保存在本地 `data/source/`，不提交到 Git。项目代码、评测集和评测报告不得包含客户数据、个人信息、凭据或未获授权的内部内容。

公开可下载不等于开放许可证。公开厂商手册和标准草案仍可能保留版权，因此本项目只在本地学习、解析和检索实验中使用这些副本，不重新分发原文件。

## 2. 语料选择原则

本项目只使用以下类型的资料：

- 自行编写的模拟机器人研发资料；
- 可以公开获取的厂商资料；
- 已获得授权的资料；
- 经过充分脱敏、可用于学习和测试的资料。

语料需要满足：

- 来源和使用边界明确；
- 不包含真实客户或个人敏感信息；
- 内容与机器人操作、故障、传感器、执行器或测试相关；
- 包含可以稳定定位的页码或章节；
- 不与其他语料大量重复；
- 能够支持可回答、跨段落和无答案问题的评测。

## 5. 数据提交规则

以下内容可以提交：

- 本语料说明文档；
- `samples/corpus/robot-fault-demo.txt` 中不对应真实客户或真实设备的最小模拟语料；
- 经过脱敏的评测问题；
- 文档解析、切分、Embedding 和检索代码；
- 不包含大段原文的统计结果和评测报告。

以下内容不得提交：

- `data/source/` 中的原始文档；
- `data/processed/` 中的解析结果；
- `chroma_data/` 中的向量数据库；
- `.env` 和任何 API Key；
- 未脱敏的日志、设备标识或个人信息。

`.gitignore` 当前使用：

```gitignore
data/source/*
!data/source/.gitkeep
data/processed/
chroma_data/
```

因此完整语料文件和新建的 Markdown 测试规程都只保存在本地，不进入 Git；`.gitkeep` 只用于保留目录结构。公开仓库中的 `samples/corpus/robot-fault-demo.txt` 是另行编写的最小模拟样例，只用于让代码审阅者验证 TXT 摄取流程，不能复现完整 V4 知识库或正式评测指标。

## 7. 当前语料使用注意事项

1. 厂商手册只描述对应产品，不能自动推广到其他机器人部件。
2. 标准文件是征求意见稿，不能描述为已经正式生效的强制标准。
3. 自编故障码和测试阈值都是模拟数据，不能描述为京东或设备厂商内部参数。
4. 后续引用必须来自实际检索 Chunk，由代码返回 `source_file`、`page_or_section` 和 `chunk_id`，不能让 LLM 自造来源。
5. 后续建立评测集时，要专门包含能够检验上述边界的无答案问题和反事实问题。
