# RobotOps Copilot 演示脚本

## 1. 3–5 分钟项目讲解提纲

### 第一部分：背景与问题（约 40 秒）

- 机器人故障诊断依赖日志、工程手册、状态数据和现场图片。
- 直接使用 LLM 存在无来源补全、权限失控和高风险建议问题。
- 项目目标是只读诊断辅助，不是自动控制。

### 第二部分：架构（约 90 秒）

- 文档摄取：解析、Chunk、Embedding 和 Chroma。
- 检索：归一化、关键词与向量双路、RRF、重排和门控。
- Agent：Planner 负责下一步选择，Runner 控制循环，Executor 校验工具。
- 安全：Planner 前的安全分类和请求级最小工具范围。
- 多模态：图片校验、请求级引用、Vision 结构化观察和来源分层。
- 交付：SSE、会话、控制台、导出和 Docker。

### 第三部分：关键取舍（约 60 秒）

- 工具权限不交给模型。
- 引用元数据不由模型生成。
- Vision 观察不等于工程事实。
- 离线 Fixture 与真实模型结果分表统计。
- 高风险请求可以观察，但必须转人工审核。

### 第四部分：结果与限制（约 60 秒）

- 30/30 固定离线场景、34/34 安全专项和 2655/2655 自动化测试。
- 真实模型严格 4/10，人工复核 6 通过、2 部分、2 失败。
- 当前限制包括真实模型稳定性、特定页检索、成本不可估算和无生产基础设施。

### 第五部分：后续方向（约 30 秒）

- 子任务—证据覆盖矩阵。
- 更稳定的结构化 Planner 输出。
- 更强的检索重排与视觉质量预检。
- 在真实设备接入前补齐认证、审计、仿真和工业安全评审。
