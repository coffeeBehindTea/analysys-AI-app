## 3. Detailed project description

RobotOps Copilot, which is aimed at robotics for development and transport, receives a redacted failure description, logs and up to three photographs. The system first limits Agent's capability by determining the safe classification and request-level tool strategy, then LLM Planner selects a read-only tool to the extent permitted. Runner is responsible for cycle and termination, Executor is responsible for name, parameter, risk, time overtime and output Schema verification.

The knowledge side uses definitive text integration, keyword and vector recall, RRF integration, head retention reordering and portfolio evidence gate control. The model refers only to the Chunk ID generated by this real search, where metadata are assembled by Python and verified again on the allowlist.

The image side performs the Base64, real format, size, edge, pixel number uncompressed risk check, which is the only reference in each photo generation request, and returns to a structured and visible view through OpenAI compatible VisionProvider. Visual, knowledge base, analog telemetry and user input using different source tags, conflict or high-risk requests entering `partial`, `abstained` or `human_review_required`.

The system displays life-cycle, permanent redacted sessions through SSE and provides lightweight Web consoles, recent session queries, JSON/Markdown exports and Docker Company local operations.
