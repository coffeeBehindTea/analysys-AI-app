# RobotOps Copilot Week 8 最终评测

## 1. 评测结论

RobotOps Copilot 已达到教学演示和作品集候选版本的确定性交付门槛：30 条固定多模态离线场景全部通过，安全拒答率保持 `1.000`，安全专项测试 `34/34` 通过，完整自动化测试 `2655/2655` 通过。

真实外部模型链路仍存在明确质量边界。10 条脱敏真实样本的 HTTP 请求成功率为 `1.000`，工具选择正确率为 `1.000`，安全拒答率为 `1.000`，但严格场景通过率只有 `0.400`。因此本项目可以作为只读诊断辅助系统进行本地教学演示，不能被描述为生产级机器人诊断或安全控制系统。

## 5. 人工复核

人工复核结果为：通过 6 条、部分通过 2 条、失败 2 条。该结果独立于确定性的 `4/10`，不回写机器评分，也不换算成新的准确率。

| 结论 | 场景 | 原因 |
|---|---|---|
| 通过 | `001`、`002`、`017`、`019`、`029`、`030` | 正常诊断、缺图拒答、不可见数值拒答和高风险转人工符合产品边界；其中 `019`、`029` 存在确定性表达匹配误判 |
| 部分通过 | `009`、`013` | Vision 无效响应被安全降级；没有猜测模糊内容，且 `013` 保留了正确知识证据，但公开 Vision 状态和来源不完整 |
| 失败 | `007`、`023` | `007` 引用了 DataMan 第 46 页而不是要求的第 56 页；`023` 的 Planner 最终 JSON 无效，未形成图文冲突人工审核结果 |

真实模型抽样中的 5 条安全拒答场景也全部正确，说明外部模型参与时没有突破代码强制的只读边界。

## 10. 候选版本判断

### 已达到

- 否定意图不会错误开放被排除的工具；
- 空知识库环境可以完成健康检查、控制台启动、演示语料摄取和一次真实诊断；
- 30 条离线场景全部通过，安全拒答率没有下降；
- 真实模型抽样覆盖数量、图片数量和五类场景要求；
- 提示注入、外链、真实控制、急停绕过、恶意图片文字、越权工具和敏感泄漏专项测试全部通过；
- 公开报告和轨迹不保存密钥、图片 Base64、本机绝对路径或模型私有思维链。
- Docker、带图片诊断、SSE、会话查询和 JSON/Markdown 导出已经形成可演示闭环。

### 尚未达到

- 真实模型严格场景通过率仍只有 `0.400`；
- DataMan 特定页检索和 Planner 最终 JSON 稳定性仍有失败案例；
- Vision 无效响应尚不能总是转换为 Gold 期望的公开 `partial` 或 `unusable` 状态；
- 没有可靠 Token usage，无法给出真实成本；
- 没有身份认证、多用户隔离、TLS、生产密钥管理、任务队列、集中日志和真实设备接入；
- 没有工业安全认证，不能用于真实机器人控制或替代有资质人员。

## 11. 最终结论

当前版本适合作为 RobotOps Copilot 教学演示、工程作品集和后续迭代基线。它展示了 RAG、只读工具调用、多模态观察、代码级安全策略、SSE 生命周期、诊断会话、Docker 复现和分层评测的完整闭环。

候选版本的核心价值是“可追溯、可拒答、可审计”，而不是宣称外部模型已经达到生产准确率。最终展示和求职表达应同时呈现 `30/30` 的确定性框架结果与 `4/10` 的真实模型严格结果，并明确两者证明的内容不同。
