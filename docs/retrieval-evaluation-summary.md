## 6. 门控风险

q001、q006、q010、q013、q015 和 q016 的 Top-3 已包含完整 Gold 证据，但 Top-1 相似度低于在线门控阈值 `0.60`，因此在线 API 会直接拒答。

q008 的 Top-1 相似度接近 `0.60`，但 Top-3 没有正确证据。直接降低阈值可能放行错误检索，所以不能用单纯调低阈值替代检索优化。

## 7. 结论

纯向量检索已经达到 Week 2 的离线 Recall@3 目标，但下一阶段必须同时优化候选召回、融合排序和门控策略，并以可回答响应率、完整证据回答率和无答案安全性共同验收。
